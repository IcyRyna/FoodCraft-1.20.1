# 机器使用说明

槽位索引从 0 开始，对应原版 GUI 的槽位顺序。机器仅在服务端加工；产物和原料的容器返还物全部能放下，才提交库存变化。输出满格、产物不匹配或原料数量不足时，原料保持不变。

| 机器 | 食材槽 | 辅助槽 | 输出槽 | 默认时间 | 液体消耗 |
|---|---|---|---|---|---|
| 碾磨机 `milling_machine` | 0 | 2：燃料 | 1 | 200 tick / 10 秒 | 无 |
| 菜板 `cutting_board` | 1、2、3 | 0：菜刀 | 4 | 1 tick | 无 |
| 锅 `pot` | 0–11，主料与辅料位置按配方 | 下方灶炉供热；GUI 调火力 | 12：成品；13：失败产物 | 500 tick / 25 秒 | 无 |
| 平底锅 `frying_pan` | 0 | 下方灶炉供热；3 为旧空槽 | 1：成品；2：失败产物 | 400 tick / 20 秒 | 无 |
| 高压锅 `pressure_cooker` | 0、1、2 | 3：水；4：燃料 | 5 | 480 tick / 24 秒 | 每批 2 单位 |
| 油炸机 `deep_fryer` | 0 | 1：燃料；2：花生油 | 3 | 400 tick / 20 秒 | 每批 2 单位油 |
| 饮料制作机 `drink_maker` | 1 | 0：水 / 牛奶；3：燃料；4：冰 | 2 | 350 tick / 17.5 秒 | 每批 1 单位 |
| 酿桶 `fermenting_barrel` | 0、1、2 | 3：水；4 为旧空槽 | 5 | 3600 tick / 180 秒 | 每批 8 单位 |
| 灶炉 `stove` | 无 | 0：燃料 | 无 | 燃料原版时长 × 20 | 无 |

数据包可以为具体配方覆盖时间、数量和条件，以上为旧版默认值。具体输入输出见 `recipe-manifest.json`。

## 菜板与菜刀

将菜刀放在槽 0，食材按配方放在槽 1、2、3。熟鸡肉放在不同位置时会得到不同部位；未参与配方的食材槽必须为空。三槽同时放鸡肉不会额外产生物品。

每次成功加工消耗菜刀 1 点耐久。最后一点耐久也能完成一次加工，随后菜刀消失。黄金菜刀每批额外产出 1 个，额外产物也必须放得下。输出不能合并时不会消耗食材或菜刀耐久。

## 锅与平底锅的火候

灶炉必须位于锅或平底锅正下方并正在燃烧。旧发布记录已取消普通火焰供热，因此本移植使用灶炉供热链。

点击旧 GUI 的火焰位置调整 0–100% 火力。每 17 tick 累加一次 `火力 / 2` 的整数热量；热量达到配方区间时可以成功完成，过热产生煤，时间到而热量不足时返还第一种食材作为失败产物。失败产物槽阻塞时不提交该批消耗。

熟练度成功一次增加 1，最多 3000。旧代码实际使用固定的配方火候范围，熟练度不会改变该范围。熟练度随存档保存，并在回收机器时保存。

## 液体与容器

液体容量为 8 单位。一个水桶、净化水物品或水瓶提供 1 单位；饮料机还支持牛奶桶。水与牛奶不能混装。油炸机的对应槽只接受花生油。

水桶、牛奶桶和水瓶会在原液体槽返还空桶或玻璃瓶。容量不足、液体类型错误或返还物无法容纳时，不消耗容器。冷饮需要冰块，每个冰块提供 2500 tick 冷却时间；热饮需要燃料。

净化水桶工具对水源使用，移除一格水源并给予一个净化水物品。共可使用 16 次，第 16 次结束后工具变为一个空桶。背包满时，净化水掉在玩家附近。

## 自动化

- 顶部：食材输入。
- 侧面：燃料、菜刀、液体容器、花生油、冰等辅助物输入。
- 底部：成品、失败产物和空桶 / 玻璃瓶提取。

Forge 提供物品和液体 Capability；Fabric 提供物品和液体 Transfer API。输入水使用旧版的完整单位：Forge 为 1000 mB，Fabric 为一个 `FluidConstants.BUCKET`，最多 8 单位。液体端口不提供抽走已装液体的行为。

Forge 模拟操作与 Fabric 未提交 / 回滚事务不会修改库存或水量。顶面不能代替辅助物端口，底面不能插入物品。

顶面自动输入根据当前配方的槽位角色分配，投料先后顺序不会直接决定高压锅的主料位置。相同食材占多个输入槽时会均衡补入；缺少可匹配的配方角色或与已有材料冲突时返回未插入的物品。Forge 单次 Capability 槽位插入和 Fabric 聚合事务的批量返回量可能不同，资源守恒及最终槽位约束相同。机器拆除后，保留的旧接口也会拒绝继续插入。

加工中的数据包配方内容改变时，会重置该批进度再使用新时间和条件；仅输出阻塞会暂停相同配方的进度。JEI 转移同时检查所需数量、旧材料的返还空间和菜单快照，不能完成全部转移时保持原库存。

## 保存与拆除

库存、当前配方、进度、剩余燃烧 / 冷却时间、液体类型与数量、火力、积累热量和熟练度都写入方块实体 NBT。GUI 的燃烧时间与加工时间以两个 16 位字段同步，避免大数值被截断。

默认启用扳手。普通拆除掉落机器外壳，库存只掉落一次；扳手回收完整机器，库存和加工状态写入该机器物品，世界里的原库存先清空，防止物品和方块两次释放库存。创造模式不额外生成机器物品。

关闭 `wrench` 配置后，铁级或更高的镐可以回收机器本体。普通回收会单独掉落库存，机器物品只携带熟练度；不会把同一库存同时写进物品和掉在地上。

Forge 配置：存档内 `serverconfig/foodcraft-server.toml`。Fabric 配置：实例 `config/foodcraft.json`，格式为 `{"wrench":true}`。
