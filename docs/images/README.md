# FoodCraft 图文介绍素材

本目录的九张图用于仓库介绍与 2.0.0 发布页，内容根据当前发行版的实际资源与配方整理。

- 物品图鉴使用 FoodCraft 2.0.0 的原始 PNG 贴图，名称来自 `zh_cn.json`。
- 机器模型预览读取当前方块模型的几何、UV 和贴图。
- 菜板及高压锅示意读取当前 GUI 资源与 `machine-layouts.json`，展示输入、输出和槽位关系。
- 这些图片为资源图鉴、模型预览与配方操作示意，不是游戏场景截图。
- FoodCraft 素材保留原作者与项目贡献者署名；原版参照物来自 Minecraft 1.20.1。

原始资源文件的 SHA-256 记录在 `source-evidence.json`。图版通过浏览器 Canvas 排版并导出 PNG；插图中的灯光与排布用于展示，实际外观以游戏客户端为准。
